# 📦 Backup Automation Script

A simple and efficient **backup automation tool** built with Python.
Automatically creates timestamped backups of folders, making data management easy and reliable ⚡

---

## 🚀 Features

* 📂 Backup any folder
* 🕒 Automatic timestamped backups
* 📁 Preserves folder structure
* 💾 Multiple backups without overwrite
* 🧠 Simple and clean CLI usage

---

## 🛠 Tech Stack

* Python 🐍
* shutil (file operations)
* datetime (timestamp generation)
